# 🚆 RailConnect — Railway Management System

https://noelinegaikwad.github.io/railway-management-system-/

A responsive academic portfolio project for searching trains, reserving seats, generating demo PNRs, cancelling bookings and viewing an admin dashboard.

## Features
- Train search
- Passenger reservation
- Demo PNR generation
- Booking cancellation
- Seat availability updates
- Admin statistics and train table
- Mobile-responsive UI
- LocalStorage persistence

## Tech Stack
HTML5 • CSS3 • JavaScript

## Run
Open `index.html` in a browser or deploy the folder with GitHub Pages.

## Future Java Backend
For a full-stack version, connect this frontend to Java/Spring Boot and MySQL for authentication, users, trains, reservations, cancellations and persistent data.
